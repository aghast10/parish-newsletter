# Guía de estilo — Boletín Parroquial
## Parroquia Nuestra Señora del Perpetuo Socorro, Zaragoza

## Tono
- Cálido, cercano, comunitario.
- Esperanzador sin ser ingenuo.
- No burocrático: esto es una comunicación entre vecinos de fe, no un informe institucional.

## Lenguaje
- Español, registro coloquial-formal (usted implícito pero sin rigidez).
- Frases cortas y directas.
- Evitar jerga eclesial excesiva — que cualquier feligrés lo entienda.
- Fechas y eventos concretos cuando se mencionen.

## Estructura
- Saludo breve y acogedor al inicio.
- Una sección por cada grupo que haya enviado su contribución.
- Cierre comunitario con mensaje de unión.
- Pie de página con datos de contacto de la parroquia.

## Identidad visual (colores de perpetuosocorro.com)
- **Granate principal**: #770024 — cabecera, encabezados de sección.
- **Burdeos**: #b30c3c — acentos, enlaces, botones.
- **Dorado**: #a39b5c — detalles decorativos, líneas separadoras.
- **Fondo**: #fffdf9 (crema cálido) — fondo del cuerpo del boletín.
- **Texto**: #282828 (carbón) — texto principal.
- **Fondo oscuro**: #282828 — pie de página.

## Tipografía
- Encabezados: Montserrat (fallback: Arial, sans-serif).
- Cuerpo: Open Sans (fallback: Helvetica, Arial, sans-serif).

## Logo
- URL: https://perpetuosocorro.com/wp-content/uploads/go-x/u/b32e3365-10bb-4a7f-aaed-bcdfaf04da21/image.png
- Circular, granate con cruz blanca estilizada.
- Usar en cabecera sobre fondo granate, tamaño ~60px.

## Formato HTML para email
- HTML con estilos inline para compatibilidad con clientes de correo.
- Ancho máximo: 640px, centrado.
- Usar tablas para layout (compatibilidad email).
- Encabezados claros para cada sección.
- Separadores dorados finos entre secciones.
